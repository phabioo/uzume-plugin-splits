# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

uzume-plugin-template is the starting point for new Uzume plugins: a minimal example plugin skeleton (`manifest.json`, `main.lua`, `i18n/`, `assets/`) with tests against synthetic data and a CI and packaging setup, planned together with plugin API v1.

## Relation to Uzume

- Plugin for [Uzume](https://github.com/phabioo/uzume) (self-hosted retro gaming platform). Interface: `docs/architecture/12-plugins.md` and `docs/guides/plugin-api.md` in the Uzume repository.
- Plugin API v1 ships with Uzume since 0.11 (`docs/guides/plugin-api.md` there); this repository has no code yet. Open API items are marked open, never invented.
- Runtime: Lua 5.4 in the Uzume sandbox; UI only as declarative building blocks (no QML).

## Working rules

- Repository language is English: code, comments, UI strings, docs, commit messages and PRs.
- Opus only orchestrates and writes no product code; implementation is done by the Sonnet 5.5 agents in `.claude/agents/`, searching and log reading by the Haiku agent `scout` (alias `haiku`).
- Briefs follow the template in `docs/workflow.md` (which also holds the token-saving rules).
- Opus verifies via `git diff --stat`, a targeted diff and the test result; commit/PR by Opus. One work package per thread, one topic per PR.

## Hard rules

- No ROMs, BIOS, firmware, game files, extracted assets, sprites, maps, text dumps or RAM dumps of real games in the repository or in tests. Tests use only synthetic data generated by code from documented formats.
- Nintendo/Pokémon names may appear as text identifiers only.
- Never put secrets in files, profiles or logs.
- Never overwrite saves silently.

## Languages

- Target versions are the German/EU releases first. Adapters support all language versions of a game where feasible, at least German and English.
- Names of species, moves, items and locations are read from the game at runtime so they appear in the game's language; they are never shipped as tables. Our own data tables are keyed by internal IDs, not names.
- Plugin UI strings come from i18n files (`i18n/`): English is the source, German the first translation.
